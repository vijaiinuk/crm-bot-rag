## Home page

**Home** is the first page you see after you sign in. To return to it from anywhere, select the logo at the top of the main menu.

The main menu runs down the left side of every page. It has one entry per module you can use, for example **Deals** or **Support**. If an entry is missing, your administrator hasn't licensed that module for you.

Three things stay in the same place on every page:

- **Global search** is the search bar at the top. It only finds records in modules you can use.
- **Notifications** is the bell icon at the top. In-app notifications appear here and are kept for 90 days. After that they are removed automatically.
- Your profile picture is in the top-right corner. Select it to open **My settings**, where you manage your profile and personal preferences.

The center of **Home** shows your recent activity and any items you have pinned to **Favourites**.

## Search

Use **Global search** to jump straight to a record or page without browsing the main menu. For more ways to narrow your results, see *Search tips*.

1. Select **Global search** at the top of any page, or press **/**.
2. Type at least two characters of a name, email address, phone number or title. Results appear as you type and are grouped by module.
3. Select a result to open it. To see the full list instead, press **Enter**.
4. To reuse a search later, select **Save search** on the results page, enter a name and select **Save**. You can keep up to 50 saved searches. If you reach the limit, delete one you no longer need before you save a new one.

## Favourites

Pin the records and pages you open most so you can reach them in one click. You can pin up to 20 records or pages to **Favourites**.

1. Open the record or page you want to pin.
2. Select the star icon next to the page title. The star fills in to show the item is pinned.
3. To open a pinned item later, select the star icon next to **Global search** and choose the item from the list. To remove an item, open the list and select the filled star beside it.

If the star doesn't respond, you have reached the limit of 20. Remove an item you no longer need and try again.

## Keyboard shortcuts

Shortcuts work on any page, except while you are typing in a field. Press **?** at any time to see this list in the app.

| Shortcut | What it does |
|---|---|
| **/** | Moves the cursor to **Global search** |
| **G** then **H** | Opens **Home** |
| **G** then **N** | Opens **Notifications** |
| **G** then **F** | Opens your **Favourites** list |
| **G** then **S** | Opens **My settings** |
| **Esc** | Closes an open panel, list or search results |
| **?** | Shows the list of keyboard shortcuts |

To use a two-key shortcut, press the first key, release it, then press the second key within one second.
