## Search operators

Type these operators into **Global search** at the top of any page. You can combine them in one search. Results only include records in modules you can use.

```
"annual contract"        exact phrase
renewal -expired         exclude a word
acme OR globex           either word
owner:me                 records you own
created:>2025-01-01      created after a date
#vip                     records tagged "vip"
#vip #emea               records with both tags
#vip owner:me            tag plus another operator
```

Lines that begin with `#` are tag searches. Type the tag name directly after the `#`, with no space.

## Saved searches

Save a search you run often so you can repeat it in one click. You can keep up to 50 saved searches.

1. Enter your terms and operators in **Global search** and press **Enter**.
2. On the results page, select **Save search**.
3. Enter a name that describes the search, such as "My VIP renewals", and select **Save**.
4. To run it again, click **Global search**, open **Saved searches**, and select the name.

If you reach the limit of 50, delete a search you no longer use before you save a new one. For more on moving around the product, see *Finding your way around*.
