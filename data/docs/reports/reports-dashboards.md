## Create a dashboard

A dashboard holds up to 24 widgets. New dashboards are private until you share them.

1. Go to **Reports → Dashboards**.
2. Select **New dashboard**, then enter a name for the dashboard.
3. Select **Add widget** and choose a widget type: number, bar chart, line chart, table or funnel.
4. Choose the report that supplies the widget's data, enter a widget title, and select **Add**. If you haven't saved the report you need yet, build it first in **Reports → Report builder**.
5. Repeat steps 3 and 4 for each widget, drag widgets to arrange them, and select **Save**.

Report data refreshes every 15 minutes, so a widget can lag slightly behind the latest changes in your account.

A report only shows data from modules the person viewing it can use. If a colleague isn't licensed for a module that feeds one of your widgets, that widget doesn't show them the data from that module.

## Share a dashboard

Only you can see a dashboard until you share it. You can share with individual users or with whole teams.

1. Go to **Reports → Dashboards** and open the dashboard you want to share.
2. Select **Share**.
3. Enter the name of a user or team, then choose their access level: **Can view** lets them open the dashboard, and **Can edit** also lets them change its widgets and layout.
4. Select **Save**. Repeat steps 3 and 4 to add more users or teams.

To change someone's access later, open **Share** again and pick a different level for that user or team.

## Dashboard widgets

Each widget shows data from one report. Choose the type that fits the question you want the dashboard to answer.

| Widget type | What it shows | Best used for |
|---|---|---|
| Number | A single figure from a report | Headline totals, such as open deals or new contacts this month |
| Bar chart | Values compared across categories | Comparing results by owner, team or source |
| Line chart | Values plotted over time | Spotting trends from week to week or month to month |
| Table | Rows and columns from a report | Detailed lists you want to scan or check |
| Funnel | Progressive drop-off across ordered steps | Seeing how many records move from one stage to the next |

A dashboard holds up to 24 widgets in any combination of these types. If you also want a report's data delivered by email on a schedule, see **Scheduled exports** under **Reports**.
