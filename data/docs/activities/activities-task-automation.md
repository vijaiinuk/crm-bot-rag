## Recurring tasks

Use a recurring task for work that repeats on a schedule, such as a weekly check-in with a customer or a monthly account review. Recurring tasks repeat daily, weekly or monthly. Each task has one assignee.

1. Go to **Activities → My tasks** and select **New task**.
2. Enter a **Title**, choose the **Assignee**, and set the **Due date**. To get a reminder, set **Reminder** to any time from 5 minutes to 7 days before the task is due.
3. Turn on **Repeat**. Choose **Daily**, **Weekly** or **Monthly**, then enter the number of repeats in **Occurrences**. You can create up to 52 occurrences ahead.
4. Select **Save**. Each occurrence appears in **My tasks** with its own due date. Any occurrence that passes its due date without being completed shows in red.

## Task templates

Use a task template when you create the same kind of task often, such as an onboarding checklist item or a renewal reminder. A template stores the details that stay the same, so you only enter what changes.

1. Go to **Activities → My tasks** and select **New task**.
2. Fill in the fields you want to reuse, such as **Title**, **Description** and **Reminder**. Leave **Assignee** and **Due date** empty, because you set them each time you use the template.
3. Select **Save as template**, enter a name in **Template name**, and select **Save template**.
4. To use a template, go to **Activities → My tasks**, select **New task → From template**, and choose the template. Set the **Assignee** and **Due date**, then select **Save**.

You can also turn on **Repeat** when you create a task from a template. For tasks that are created automatically when a deal moves to a new stage, see *Creating follow-up tasks when a deal changes stage*.
