## Create a task

You can create a task from the **Activities** menu or from a record page. A task has one assignee, a due date and an optional reminder.

1. Go to **Activities → My tasks** and select **New task**. To link the task to a record, open the record page instead and add the task from the activity panel.
2. Enter a **Title** and, if needed, a **Description**. Use the title to say what has to happen, for example "Send revised pricing to Dana."
3. Set the **Assignee**. Each task has exactly one assignee, and the default is you.
4. To make the task repeat, select **Repeat** and choose daily, weekly or monthly. Then select **Save**. The CRM creates up to 52 occurrences ahead of time.

The new task appears in **My tasks** for the assignee. It also appears in **Calendar** on its due date.

## Due dates and reminders

Every task needs a due date. A reminder is optional and tells the assignee before the task is due.

1. Open the task from **Activities → My tasks**, then select the **Due date** field and choose a date and time.
2. Open the **Reminder** list and choose how long before the due time you want to be notified. You can choose any time from 5 minutes to 7 days before the task is due. To remove a reminder, clear the field.
3. Select **Save**. Check **My tasks** to confirm the new due date.

Tasks that pass their due date without being completed show in red in **My tasks**. To clear the red marking, either complete the task or move its due date to a later time.

If you change the due date of a task that has a reminder, the reminder moves with it and keeps the same interval. For example, a reminder set to 1 day before still fires 1 day before the new due date.

## Complete or reassign a task

Complete a task when the work is done. Reassign it when someone else should take it over.

1. Go to **Activities → My tasks** and find the task. Use the filters above the list to narrow it down if you have many tasks.
2. To finish the task, select the checkbox next to it, or open the task and select **Mark complete**. The task moves out of your open list. If the task repeats, the next occurrence stays scheduled.
3. To hand the task to someone else, open it, change the **Assignee** to another user and select **Save**. The task leaves your **My tasks** list and appears in the new assignee's list. Because a task can have only one assignee, you can't share it between people.

If you need a record of a phone conversation that came out of a task, use **Log a call** in the activity panel on the record page. Choose one of the call outcomes: **Connected**, **Left voicemail**, **No answer** or **Wrong number**. Logging a call doesn't complete the task, so complete the task separately.
